# Free, ad-free release

The owner's latest instruction makes this release completely free and ad-free. It supersedes every earlier price, subscription, lifetime, gift, product-ID, licensing-key and entitlement-gate requirement. No payments profile is needed for this release. All supported game-launch paths use the existing native preparation/recovery flow directly, without purchases or an app login. Previously approved restricted-core exclusions and the pre-existing 3DS UI limitation remain unchanged.

Removed: Google Play Billing client dependency, store/configuration/signature/entitlement implementation, checkout/restore/manage/gift controls and purchase access checks in GameLauncher. Obsolete billing-only unit tests are removed with that feature. SaveArchive implementation/tests and the independent document-picker export screen remain; exports copy originals, refuse export during active gameplay and do not alter saves. Internal activity/resource names retain their old billing identifiers to avoid unnecessary component churn; the user-facing screen is Save export. Optional Drive synchronization remains optional and is not a gameplay/login requirement.

Native binaries and corresponding sources are identical to FULL_SOURCE_CORE_CHECKPOINT.md. The source export cleanup also omits unused nested Windows SDK/macOS/test compressed archives. melonDS freebios is an independently authored BSD replacement, not Nintendo BIOS: its original source, assembly/Makefile, binaries and copyright notice remain in the corresponding source package. No commercial ROM/BIOS/art is included.

Remaining launch gates: owner-approved upload signing and applicable Play App Signing handoff, cloud Console free listing/privacy/reviewer configuration, source publication and Play-delivered testing. No local Console actions, keys, credentials, software installations or agreement acceptance occurred. The cloud worker owns Console changes. Independent DS/physical/save compatibility and clean exported-source rebuilds remain unrun; all previous QA caveats apply.

Privacy/listing handoff: remove purchase history/receipt/product configuration claims and all paid offers from the listing and privacy draft. The merged release manifest has no BILLING or AD_ID permission. No ads SDK was introduced. Cover lookup still sends normalized game titles over HTTPS to thumbnails.libretro.com when artwork is requested. Optional Google Drive sync still uses a separately authorized Google account and save files; do not describe the whole app as having no network/account features. PSP assets remain packaged locally with no Play-flavor download fallback. Gameplay itself requires neither login nor payment.

Free-build QA:203 unit tests PASS (obsolete billing tests removed), lint0errors/44warnings/4hints; twelve instrumented checks PASS, including no checkout/login UI and the real save-export document picker. Native hashes remain identical to the actual16KB-tested set. Final app notices include melonDS generated combined attribution (90 new notice records).

Final minified free external-launch gameplay PASS: normal ExternalGameLauncherActivity loads FCEUmm and renders the original NES homebrew fixture without payment/login. Screenshot pixels inspected. Earlier render assertions failed because the stock Pixel Fold profile correctly triggered the unchanged horizontal-hinge guidance. The successful test used Android's emulator-only global display_features `fold-[0,920,2208,920]` and device_posture3 override, with native2208x1840 and rotation0. This validates emulated geometry, not a physical folding device. Original AVD configuration and unset fold globals are restored after QA. No production test bypass was added.
