The production fix measures an accessible-button pulse in actual core runs: two runs pressed, followed by one run released before another queued pulse. It tracks pulse state separately from physically held state, so releasing a held key does not erase a queued accessible press and pulse completion does not release a physical hold. Cancellation generations invalidate stale queued work; pause, gate and shutdown paths clear pulse state. Per-key queues are capped at 64 and invalid inputs are rejected. The strict normal-tap active-save and restoration reruns now pass on this candidate. Pulse/ordinary-hold overlap remains host-tested rather than an Android or hardware-gamepad certification.
